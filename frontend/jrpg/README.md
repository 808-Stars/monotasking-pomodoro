# 灯火冒险：Pages发布快照

此目录由当前`monopomo-jrpg-demo`导出，用于MONOPOMO同站`/jrpg/`发布，不是第二套规则或美术源稿。

效率前端的`npm run build`完成后通过`postbuild`构建本目录，输出`dist/jrpg`。依赖复用父工程，图片以原尺寸、含透明背景的无损WebP保存，URL在导出时统一加`/jrpg/`前缀。`release-manifest.json`记录发布素材，不包含存档、环境变量或美术源文件。

游戏的1920×1080逻辑画布使用同源iframe，因此全站`X-Frame-Options`设置为`SAMEORIGIN`，不允许其他站点嵌入。入口为登录页“进入灯火冒险”和已登录侧栏“灯火冒险”；游戏右上可返回工作台。

本次为浏览器本地存档测试版。尚未实现工作事件→游戏体力、账号隔离的游戏云存档或公共排行榜；部署入口不等于这些功能已完成。不要清空效率工具或游戏存档来更新发布。

后续从规范的Demo源目录重新导出至新的空发布目录，对照清单更新本快照；不要在这里重绘资源或改动游戏规则后忘记同步主工程。
