## 2. 已锁定的战斗契约

### 2.1 单一敌方目标

- 手动战斗永远是四名角色对一个门首领或魔王。
- 不存在随机小怪、召唤物、复数敌人或可单独选择的首领部位。
- 玩家所有攻击技能只指向当前首领。
- “全体”只用于己方四人治疗、护盾、增益或首领对队伍的群体攻击。
- 首领复杂度来自阶段变化、意图预告、蓄力、弱点变化、增益和异常抗性。

### 2.2 技能携带

每名角色固定拥有：

- 一个自动生效的中央本能。
- 三个 Lv1 基础主动技能。
- 一个独立于主动栏的固定奥义。
- 主职责、副职责、羁绊三条各五节点的技能树，共十五个节点。
- 每条分支均为“入口 → 两个并行中层 → 关键 → 顶点”。

战前从全部已解锁主动技能中恰好携带三个。奥义单独携带，不占主动栏。普通被动解锁后自动生效；多个顶点可以解锁，但战前只能启用一个。羁绊节点只有角色位于当前四人编队时生效。

### 2.3 多武器携带

- 六种武器的中文显示名固定为：剑、长枪、短剑、斧、弓、杖。
- “长枪”的内部类型 ID 为 spear，专指突刺、横扫或投掷使用的冷兵器长枪。
- 系统不存在火枪、手枪或任何其他火器类别；角色文案、美术、图标和动画不得出现枪械、子弹、弹药、弹匣、扳机、枪口或开火表现。
- 每名角色可同时装备其每种熟练武器各一件。
- 普攻时先选择“攻击”，再选择武器。
- 物理主动技能固定要求一种武器；缺少该武器时技能不可使用。
- 一次攻击只读取实际使用武器的攻击属性与词条，多个武器属性不叠加。
- 元素魔法不要求指定武器，使用已装备武器中的最高魔攻。
- 短剑允许出现次级魔攻词条，以支持舞者和药师；杖仍是最高魔攻武器。
- 多武器的常驻属性取值方式应在装备规格修订时统一定义，但不得把所有武器面板直接相加。

### 2.4 Break 与行动

- 表中的 B 是技能正文自带的 Break 总值；多段技能会明确写出每段或总值。
- 命中武器或元素弱点仍按全局规则追加 Break。
- 条件被动、羁绊和装备提供的额外 Break，单次行动合计最多 +2B。
- 每名角色每轮最多执行一个完整行动。
- 反击、追射、DOT 和被动触发不算完整行动，也不能再次触发完整行动链。
- 任何技能都不能给予追加回合、复制行动或无限 MP/蓄力循环。
- 同类别增益或减益只保留数值最高者，较弱效果只能刷新合法持续时间，不能通过换名称重复叠加。

### 2.5 数值上限

| 效果 | 全局上限 |
|---|---:|
| 总增伤 | +50% |
| 总减伤 | 35% |
| 条件额外 Break | 单次行动 +2B |
| 护盾 | 目标最大生命的 40% |
| 速度增益 | +40% |
| 闪避 | 25% |
| 队友被动 MP 回复 | 每名角色每轮 2MP |
| 队友被动蓄力 | 每名角色每轮 15 |
| 单轮蓄力总增加 | 每名角色 35 |

### 2.6 异常与普通减益

普通物理攻击和未明确写出异常的伤害技能绝不附带异常。攻击、魔攻、防御、速度、命中等百分比变化属于普通增减益，不算异常。

| 异常 | 对普通角色 | 对首领 |
|---|---|---|
| 中毒 | 行动结束受到伤害，3 回合 | 同左 |
| 流血 | 使用物理技能后受伤，每轮一次，3 回合 | 同左 |
| 灼烧 | 较强持续伤害，2 回合 | 同左 |
| 冻伤 | 速度 -20%，2 回合 | 同左 |
| 致盲 | 命中 -25%，2 回合 | 同左 |
| 诅咒 | 受到的治疗与护盾 -30%，2 回合 | 同左 |
| 浮空 | 每轮首次受到长枪、弓或风攻击时额外 +1B，2 回合 | 同左 |
| 沉默 | 下一次行动不能使用魔法，随后解除 | 转为下一次魔法行动效果 -20% |
| 麻痹 | 下一次行动有 50% 失败，随后解除 | 转为下一次行动速度 -20% |
| 眩晕 | 跳过下一次行动，随后解除 | 立即削减 2B |

硬异常只出现在高阶、明确标注且低频的技能上。首领的韧性转换不会跳过行动，避免连续控制取代 Break。

## 3. 八职业总览

### 3.1 职责、武器与元素

| 职业 | 物/法倾向 | 熟练武器 | 元素魔法 | 主职责 | 明确短板 |
|---|---|---|---|---|---|
| 战士 | S / D | 剑、长枪、斧、弓 | 无 | 物理输出、承伤、挑衅、护卫 | 无魔法、治疗和资源支援 |
| 舞者 | B / B | 短剑、剑 | 暗、冰 | 攻击增益、首领减益、节奏组织 | 无治疗、护盾、承伤和追加行动 |
| 商人 | A / C | 长枪、弓、剑 | 火、风 | 筹码、MP、蓄力与风险契约 | 不能成为最高输出，筹码有限 |
| 学者 | D / S | 杖、短剑 | 火、冰、雷、风 | 最高魔法输出、弱点解析 | 生存弱，不承担治疗和主要物理 Break |
| 神官 | D / A | 杖、长枪 | 光、冰 | 群体治疗、复起、防御增益 | 输出低，单体持续治疗不如药师 |
| 盗贼 | S / D | 短剑、剑、弓 | 火 | 单体减益、偷势、处刑爆发 | Break 较低，无治疗与承伤 |
| 猎人 | S / D | 弓、斧、长枪 | 雷 | 多段 Break、追猎、预警、驱散 | 无治疗、护盾、承伤和完整解析 |
| 药师 | B / A | 斧、短剑 | 光、暗、雷 | 单体持续治疗、净化预防、异常瓶剂 | 群体救场和复起弱于神官 |

### 3.3 节点成本

每条分支指定一个材料家族。入口和中层只消耗 SP；关键、顶点和 T4 升格使用该分支家族。

| 层级 | 成本 |
|---|---|
| 入口 | 1SP |
| 中层 A / B | 各 1SP |
| 关键 | 2SP + 同家族 T1×2 + T2×1 |
| 顶点 | 3SP + 同家族 T2×1 + T3×1 + 职业许可证 |
| T4 升格 | 0SP + 同家族 T4×1 + 王阶催化剂×1 |

T4 升格强化对应顶点，不增加第四个顶点。只有当前启用顶点及其升格效果进入战斗快照。

## 4. 战士

**定位：** 物理输出与队伍承伤核心。所有角色仍可成为首领目标；战士通过挑衅、护卫和伤害转移主动承担压力。
**武器：** 剑、长枪、斧、弓。
**元素：** 无。
**短板：** 不会元素魔法，不治疗，不提供 MP 调度。

### 4.1 本能、基础技能与奥义

| 类型 | 名称 | 效果 |
|---|---|---|
| 中央本能 | 坚忍 | 每场首次低于 40% HP 时，本轮受到伤害 -20%，并获得 15 蓄力 |
| 基础主动 | 连环斩·剑 | 2MP，两段各 75% 物理伤害、各 1B |
| 基础主动 | 贯阵突刺·长枪 | 2MP，165% 物理伤害、2B；首领正在蓄力时伤害 +15% |
| 基础主动 | 挑衅 | 1MP，持续两轮；可转移的单体攻击优先指向战士，不可转移攻击改为伤害 -12% |
| 固定奥义 | 不破战线 | 一轮内其他队友受到伤害 -25%，所阻止伤害的一半转移给战士；每次首领行动的转移上限为战士 30% 最大生命。轮末若战士存活，以剑反击 180% 伤害、1B |

## 5. 舞者

**定位：** 攻击增益、首领减益与行动节奏组织。
**武器：** 短剑、剑。
**元素：** 暗、冰。
**短板：** 无治疗、护盾、承伤和持续资源供给；绝不追加完整行动。

## 6. 商人

**定位：** 使用本场筹码调度 MP、蓄力和风险契约，并提供有限的应急护盾。
**武器：** 长枪、弓、剑。
**元素：** 火、风。
**短板：** 自身伤害为中低档；无治疗、硬控和持续筹码产出；绝不影响战斗外经济。

### 6.1 本能、基础技能与奥义

| 类型 | 名称 | 效果 |
|---|---|---|

## 11. 药师

**定位：** 单体持续治疗、净化后的保护、确定性异常预防和稀有瓶剂异常。
**武器：** 斧、短剑。
**元素：** 光、暗、雷。
**短板：** 群体瞬时治疗和复起弱于神官，不具备坦克能力。

### 11.1 本能、基础技能与奥义

技能分为治疗、防疫、瓶剂三类。

| 类型 | 名称 | 效果 |
|---|---|---|
| 中央本能 | 配伍反应 | 连续两次行动使用不同类别技能时获得 1 层反应，最多 2 层；满层后下一技能 MP -1，治疗、持续恢复或瓶剂伤害 +15%，随后清零；净化与免疫等非数值效果不变 |
| 基础主动 | 复原药 | 2MP，单体回复 22% 最大生命，并在随后两轮各回复 5% |
| 基础主动 | 净症药 | 2MP，解除单体一个负面状态并回复 8% 最大生命 |
| 基础主动 | 雷光瓶·雷 | 2MP，115% 雷属性魔法伤害、1B |
| 固定奥义 | 万灵灵药 | 全队回复 18% 最大生命、各净化一个负面状态，并在两轮内免疫下一次新负面状态；不能复起 |

### 11.2 主职责：临床（光）

| 层级 | 节点 | 类型 | 效果 |
|---|---|---|---|
| 入口 | 精确剂量 | 被动 | 单体治疗与持续恢复 +10%，最大 MP +1 |
| 中层 A | 缓释药 | 主动 | 2MP，单体队友在随后三轮各回复 7% 最大生命 |
| 中层 B | 预防剂 | 主动 | 2MP，单体队友在两轮内免疫下一次新负面状态 |
| 关键 | 对症用药 | 被动 | 成功净化后，目标受到伤害 -10%，持续两轮 |
| 顶点 | 专科诊疗 | 被动 | 单体治疗与持续恢复 +25%，群体治疗效果 -20% |

**T4·专科诊疗：** 单体治疗与持续恢复提高至 +30%，群体治疗惩罚降为 -10%。

## 14. 平衡风险与约束

### 14.1 Break 叠加

猎人、学者羁绊、舞者羁绊、商人期货和装备可能同时提供 Break。结算顺序必须是：

1. 读取技能正文 B。
2. 判断一次弱点追加。
3. 汇总所有条件额外 B。
4. 把条件额外 B 截断到 +2。
5. 应用首领阶段免疫或修正。

### 14.2 MP 与蓄力循环

- 商人额外筹码每场最多两枚，所有筹码战斗结束清零。
- 每名队友每场只能接受一次紧急垫款、振奋分红和 Break 期货。
- 舞者只提供少量触发蓄力，不提供主要 MP 回复。
- 学者减费、神官余响、药师配伍和商人支援都不能把技能降为 0MP。
- 单轮蓄力仍受每角色 35 的总上限。

### 14.3 防御叠加

- 战士减伤与神官减伤相加后截断到 35%。
- 护盾总量截断到 40% 最大生命。
- 战士的伤害转移在减伤之后计算，并受每次首领行动的明确上限。
- 军魂不散每场只触发一次；不能和其他保命效果循环触发。

### 14.4 异常锁

- 战士眩晕、盗贼沉默、猎人浮空，以及药师的诅咒和麻痹均有每场次数或高阶节点限制。
- 首领硬异常只执行韧性转换。
- 同名异常不叠层，只刷新到合法最大持续时间。
- 高纯萃取最多把异常延长一轮，仍不能越过三轮总上限。

### 14.5 单目标语言

静态目录不得出现“所有敌人”“随机敌人”“敌方全体”“弹射到另一目标”或“切换猎印目标”。首领可以攻击己方全体，玩家不能攻击复数敌方目标。

## 15. 自动验收要求

静态规则验证器必须检查：

- 恰好八个职业。
- 每职业恰好一个本能、三个基础主动、一个奥义、十五个节点、三个顶点和三个 T4 升格。
- 每个物理主动技能恰好绑定一种武器。
- 每个角色至少两种熟练武器。
- 除战士外，每个角色至少有一种元素攻击魔法。
- 所有玩家攻击目标类型均为当前唯一首领。
- 羁绊节点只在角色入队时进入快照。
- 战斗快照恰好包含三个主动和一个奥义。
- 同时只启用一个顶点。
- 技能目录中不存在金币、EXP、掉落、材料、保底、商店折扣等战斗外收益字段。
- 硬异常在首领端全部走韧性转换。
- 多段伤害的总 B 明确且不按段重复读取。
- 武器类型 ID 只能是 sword、spear、dagger、axe、bow、staff，spear 的中文显示名必须为“长枪”。
- 职业、技能、装备、美术提示和动画配置中不得出现火枪、手枪、枪械、子弹、弹药、弹匣、扳机、枪口或开火语义。

平衡模拟至少覆盖：

- 八选四的全部 70 种队伍组合。
- 四个门首领与三阶段魔王。
- 首领无弱点、单一武器弱点、单一元素弱点和阶段换弱点场景。
- 极端增伤、减伤、护盾、Break、MP、蓄力和异常抵抗叠加。
- 有神官/无神官、有战士/无战士、有猎人/无猎人的失败路径。
- 三种顶点分别启用以及 T4 升格后的上限。
