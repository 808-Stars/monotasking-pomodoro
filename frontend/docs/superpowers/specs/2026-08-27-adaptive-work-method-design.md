# 单×番自适应工作法 1.0 设计

## 目标

把现有日报、周报、月报从“事后统计”升级为“个人基线 + 可信度 + 行动建议”的自适应工作系统。系统只比较用户自己的历史，不做群体排名，不把观察性相关包装成因果结论。

## 工作循环

1. 定向：每日计划指定一个核心任务。
2. 单核执行：工作番茄钟绑定任务，减少频繁切换。
3. 主动恢复：记录工作与休息序列，而不是只累计总时长。
4. 闭环：连接计划、专注、完成和回顾。
5. 校准：根据个人历史更新高效时段、工作负荷和任务估算。

## 数据与可信度

- 现有 `pomodoro_sessions` 继续作为完成记录和报告主数据。
- 新增 `focus_timer_events`，记录 START、PAUSE、RESUME、RESET、FINISH、COMPLETE 事件，用于观察中断和完成路径。
- 报告查询额外读取周期开始前 28 个逻辑日作为个人基线，但周期 KPI 仍只统计所选周期。
- 样本量分级：少于 5 次为“数据不足”，5–14 次为“初步”，15–29 次为“中等”，30 次以上为“较稳定”。
- 若事件表尚未部署，页面必须降级到完成记录推断，不能导致报告页面失败。

## 自适应指标

### 黄金专注窗口

按上海时区小时聚合工作会话。使用 Beta-Binomial 收缩，先验强度为 6，避免少量样本占据第一名。若事件数据存在，以运行结果作为成功/未成功样本；否则只展示投入分布并降低可信度。

### 单核纯度

用各任务专注分钟占比的 Herfindahl 指数衡量集中程度，再根据相邻工作会话的任务切换率扣减。单任务周期按 100 分处理。

### 可持续负荷

按逻辑日累计专注分钟。使用前 28 天的中位数和 MAD 建立稳健区间，避免极端冲刺扭曲平均值。没有足够历史时只展示趋势，不给过载结论。

### 计划闭环

展示记录计划、设置核心任务、核心任务获得专注、计划完成、完成回顾五个阶段。漏斗每一级不得高于前一级。

### 估算校准

对已完成任务比较 `estimated_pomodoros` 与 `completed_pomodoros`。展示散点图和中位数校准系数；少于 5 个任务不生成调整建议。

### 工作法画像

雷达图展示目标清晰、单核程度、专注稳定、恢复结构、估算校准、复盘闭环六个独立维度。画像用于发现短板，不合成新的绩效排名。

## 建议策略

建议必须包含：观察、证据量、下一步动作。证据不足时使用“可以尝试”，不得使用“证明”“一定”“最佳”等因果措辞。每次最多展示四条，优先顺序为：闭环缺口、频繁切换、可持续负荷、高效时段、估算偏差。

## 非目标

- 不做医疗、心理或疲劳诊断。
- 不根据单日数据给出稳定人格或晨型/夜型标签。
- 不引入大型图表依赖；图表继续使用 CSS 与 SVG。
- 不自动改变用户的计时器时长，只提供带可信度的建议。
