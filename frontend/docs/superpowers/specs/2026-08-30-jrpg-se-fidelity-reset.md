# 单×番 JRPG《歧路旅人 II》规则忠实适配重置规格

> 状态：用户已确认采用 A｜规则忠实复刻、内容适配  
> 日期：2026-08-30  
> 性质：现行最高优先级裁决  
> 最后裁决更新：2026-08-31；职业范围、地图系统与平衡边界已按用户确认收窄  
> 适用范围：战斗、八基础职业、技能、角色固有系统、异常状态、装备、道具、成长、副职业、敌人与首领接口  
> 不包含：前端实现、数据库迁移、原作剧情／地图／美术／音频复制

## 1. 裁决

“单×番”的 JRPG 内核不再以早期自研限制为起点，而以《歧路旅人 II》的系统关系为起点。

采用方式为：

1. **规则忠实：**原作已有的战斗规则、职业结构、技能功能、状态关系、装备语义、道具语义和成长关系，默认保留。
2. **内容适配：**14 日周目、四资源副本、原创首领、六相材料、营地设施和生产力映射可以使用原创内容，但不得反向改写原作内核。
3. **最小改造：**只有原作机制依赖本项目不存在的开放地图、普通刷怪、NPC 城镇生态或长周期经济时，才允许建立等价接口。
4. **禁止先验削平：**不得仅因为担心强度、组合复杂或实现困难，就预先加入原作不存在的行动上限、削盾上限、状态转化或扩散白名单。
5. **先复现、后平衡：**先让组合按原作关系成立，再通过首领数值、阶段、资源供给和公开抗性做平衡；不能先阉割组合再证明它“安全”。
6. **范围服从工作系统：**忠实对象集中在战斗语法与八基础职业。原作的额外职业、昼夜切换和 16 种地图指令不进入当前范围，不能为了“复刻完整”增加用户管理负担。
7. **不追求组合齐平：**职业组合允许有强弱、专精和冷门选择，不得为实现“所有组合都不弱”而创造补丁式联动。
8. **允许首领偏向：**首领可以奖励或压制特定职业与构筑，只要相性通过公开弱点、意图、阶段和图鉴表达，不使用不可见的职业修正。

本裁决覆盖此前提出但未经再次确认的硬性限制。旧文与本规格冲突时，旧文自动失效，无需逐条等待删除后才停止生效。

## 2. 规则优先级

从高到低依次为：

| 优先级 | 内容 | 说明 |
|---:|---|---|
| P0 | 现实成果保护 | 专注分钟、任务、计划、笔记、报告和已生成的工作结算永不因游戏失败被撤销 |
| P1 | 单×番外层 | 14 个逻辑日、四资源副本、番茄结算、可挽回惩罚、现有 UI 设计语言 |
| P2 | 《歧路旅人 II》原作规则 | 战斗、职业、技能、异常、装备、道具、成长、副职业、固有行动与潜力的首要依据 |
| P3 | 必要适配 | 只解决原作世界结构与本项目外层之间的接口差异 |
| P4 | 原创内容 | 四门首领、最终魔王、六相材料、原创装备、药剂、设施和叙事表现 |
| P5 | 历史设计 | 只有不与 P0～P4 冲突时才可继续使用 |

## 3. 唯一保留的项目外层

以下内容不因原作优先而取消：

- 一个周目为 14 个逻辑日。
- 每满 25 分钟产生 1 个有效结算单位；单次工作会话最多计算 4 个，每日不设置结算上限。
- 四资源副本继续承接金币、EXP、JP 与成长／制作材料。
- 番茄结束时即锁定现实工作结算；职业、装备、战斗胜负和读档不能改变该结果。
- 游戏允许产生伤势、士气、物品消耗和挑战失败，但必须有旅馆、道具、等待、训练或重新构筑等挽回手段。
- 视觉继续使用现有产品克制、精致、低噪声的 UI 语言，不复制原作界面和美术。

普通资源获取仍以扫荡结算为主，避免生产力工具要求用户额外刷怪。原作中依赖普通敌人的“学会的技能、捕获／加工、偷取、调查”等系统，通过扫荡生成的敌人记录、演武场挑战和首领部位提供等价内容；等价接口必须保留原能力的选择成本和战斗用途。

## 4. 资料与命名依据

### 4.1 来源顺序

1. Square Enix 官方系统页、官方宣传与游戏内教程确定系统结构。
2. 《歧路旅人 II》简体中文版游戏内显示确定玩家可见名称。
3. 游戏数据、可复现实测和交叉核对的攻略资料确定官方页面未公开的倍率、目标、持续时间和例外。
4. 无法从至少两种证据确认的数字不得伪装成原作精确值；先记录来源等级，再进入实现。

### 4.2 文本与素材边界

- 沿用机制使用简体中文版官方名称。
- 不复制原作技能说明全文、剧情、美术、图标、动画、地图、角色造型或音频。
- 规则关系可以忠实实现，玩家说明必须由本项目重新表述。
- 原创首领、装备和配方不得冒充原作内容。

## 5. 必须按原作重建的系统

### 5.1 战斗基础

- 四人回合制指令战斗；最终战可以使用原作式八人分队／切换结构。
- 六种武器：剑、枪、短剑、斧、弓、杖；枪指冷兵器长枪。
- 六种元素：火、冰、雷、风、光、暗。
- 敌人拥有隐藏弱点与护盾；命中弱点削盾，护盾归零后破防。
- 破防取消敌人尚未执行的行动与下一轮行动，并提高其承受伤害；恢复行动时遵守原作的优先规则。
- BP 上限、自然恢复、使用 BP 后下一轮不自然恢复、普通攻击增加段数、技能按各自增幅规则强化，均以原作为准。
- 防御指令按原作承担减伤与下一轮行动提前，不再自创额外 BP 奖励。
- 攻击、技能、道具、防御、潜力、捕获／调合等命令的可用条件按原作关系实现。

### 5.2 属性、伤害与恢复

保留原作属性体系：HP、SP、物攻、属攻、物防、属防、命中、速度、暴击、回避。

- 物理技能使用对应武器与物攻；元素攻击采用原作的属攻武器选择规则。
- 恢复技能继续以属防为主要成长来源；固定恢复道具不强行套角色治疗公式。
- 弱点、破防、暴击、物攻／属攻强化、物防／属防弱化和武器特殊效果按原作乘区关系实现。
- 技能拥有各自的基础倍率、防御修正、命中、段数和增幅成长，废止“一张通用倍率表覆盖全部技能”的做法。
- 原作 9,999 伤害上限及突破上限的辅助技能关系继续存在，不另造“无限解除上限”。

### 5.3 职业、JP 与辅助技能

- 八名基础角色继续拥有八个固定基础职业。
- 每名角色可装备一个副职业；副职业提供原作对应的武器、属性修正、主动技能和奥义。
- 八个基础职业通过职业许可证开放副职业；每个基础职业最多取得三张许可证，而不是一张。
- 已用 JP 解锁的辅助技能在满足原作条件后可跨当前副职业装备；每名角色装备四项辅助技能。
- 技能按已学习数量递增 JP 成本；奥义在该职业其他技能学习完成后解锁，并要求最大增幅使用。
- “技能副本”的产出正式映射为 JP，不再用自创技能点规则改写职业成长。

### 5.4 职业范围

当前版本只设计八个基础职业及其副职业许可证。额外职业不进入内容目录、成长线、解锁线、材料需求、构筑模拟或未来实现模式；不得预留需要用户理解或收集的占位入口。

### 5.5 八角色固有系统

八名角色继续保留各自的：

- 固有行动或职业天赋；
- 潜力；
- 两项 EX技能；
- 与角色身份绑定、不能被副职业复制的个人机制。

当前版本不实现昼夜切换，也不复刻 16 种地图指令。酒馆、商店、图书馆、演武场、扫荡记录和首领交互均由常驻设施或通用界面承担，不绑定某名角色上场。角色差异由属性、基础职业、固有行动、潜力、EX技能和个人战斗接口维持。

### 5.6 异常状态与能力变化

废止固定十种自创异常。通用异常以原作为准：

| 通用异常 | 原作决策作用 |
|---|---|
| 中毒 | 在规定时点损失 HP |
| 沉默 | 无法使用技能 |
| 黑暗 | 物理攻击命中显著降低 |
| 恐惧 | 无法使用 BP，且不能正常获得 BP |
| 晕厥 | 在持续期间无法行动 |
| 睡眠 | 无法行动，受攻击后解除 |
| 混乱 | 无法正常选择行动并可能随机攻击 |

即死作为独立特殊异常保留；首领通常可以免疫，普通敌人、部位或特殊阶段按原作式抗性处理。

物攻、属攻、物防、属防、命中、速度、暴击和回避的上升／下降属于能力变化，不混入通用异常列表。同类强化／弱化按原作的覆盖与延长逻辑处理，不再叠加自创的 `+15%/+30%` 层数。

首领通过明确的抗性或免疫应对异常，不再把沉默、睡眠、晕厥等强行转换成减速、削盾或降伤。若某个首领阶段必须防止永久锁定，应使用原作式免疫、解除、阶段重置或部位机制，并在界面公开。

### 5.7 装备与道具

- 装备槽以原作为准：职业允许的各类武器、盾、头部、身体、两个饰品。
- 武器属性只在原作规定的持有／技能选择场景生效；元素攻击使用属攻最高的可用武器。
- 装备可以具有属性强化、异常耐性、自动状态和特殊触发，但不得用统一词条模板抹平原作装备差异。
- 通用恢复物、复活物、SP物、BP物、异常治疗物、属性攻击石和特殊战斗物按原作类别建立。
- 药师“调合”与普通背包道具保持原作中的不同资源和不同操作方式。

六相材料、Grade 与调律可以作为原创装备成长内容继续存在，但它们只能扩展装备，不得改写武器许可、装备槽、原作属性语义、原作异常耐性或职业技能效果。

### 5.8 成长与经济

- 角色等级使用 EXP；职业技能使用 JP；货币使用金币／叶币的项目显示名；装备与制作使用材料。
- 四副本分别负责这些资源的主要供给，但不改变资源原本的功能。
- 任何“额外 EXP／JP／金币”职业能力，先保留原作功能，再通过周目产出上限、战后结算对象或挑战奖励池做适配；不再默认重做成无关的战斗技能。
- 原作依赖普通战后奖励的能力可作用于本次扫荡／挑战的游戏资源，但绝不能改变真实番茄数量、专注分钟或现实任务完成状态。

## 6. 立即取消的旧硬限制

以下规则从本规格生效起停止作为现行依据：

1. 通用异常固定为十种，以及“不设置睡眠”。
2. 流血、灼烧、冻伤、诅咒、浮空、麻痹等自创状态自动占据通用异常栏；它们只有在作为首领专属机制且不冒充原作通用状态时才可重新设计。
3. 首领硬异常统一转化为降速、降伤或削盾。
4. 首领持续伤害统一按最大 HP 的 1%／3% 封顶。
5. 普通攻击和装备绝不允许附加异常。
6. 每名角色每轮最多两次完整行动，以及额外行动不能继续触发任何原作允许的联动。
7. 所有技能统一使用 `1.00/1.90/2.80/3.70` 增幅倍率。
8. 强制削盾单行动最多 6 点。
9. 自定义扩散、复制、免费施放白名单先于原作技能目标规则。
10. 每个基础职业只有一张副职业许可证。
11. 基础职业技能必须消耗自创材料、卷册或固定等级才能解锁。
12. 现行原创伤害公式、暴击倍率、BUFF层数和行动购买上限被视为原作规则。
13. 因为某个组合可能很强，就提前修改其核心效果；应先复现组合，再用敌人、资源和阶段平衡。
14. 所有 28 组职业组合都必须达到“中”以上，或每个职业必须拥有固定数量的强搭配。
15. 每名首领都必须对所有职业保持中立，并为每个职业提供等量优势或替代路线。

## 7. 内容适配准则

### 7.1 可以适配

- 原作 NPC、城镇和地图交互所承载的必要战斗内容；
- 普通敌人与随机遇敌的获取渠道；
- 原作地图、支线和神庙对应的解锁地点；
- 长流程等级、JP和金币数量级；
- 原作剧情首领替换为本项目原创首领；
- 奖励来源映射到四副本和14日周目。

### 7.2 不可随意适配

- 技能的职责与关键联动；
- BP、破防、职业、副职业、辅助技能、潜力和 EX技能之间的关系；
- 通用异常的分类与基本作用；
- 武器、元素、属性和装备槽的语义；
- 角色独有机制不能被副职业复制；
- 原作刻意设计的代价、准备动作和资源闭环。

每个适配项必须写明：原作作用、缺失环境、最小改造、保留的决策、是否影响其他原作组合。不得只写“为了平衡”。

## 9. 后续重建顺序

1. 建立原作系统与现有规则的逐项来源矩阵。
2. 重写八基础职业、辅助技能、奥义和JP解锁。
3. 重写八角色固有行动、潜力和EX技能；不建立昼夜或地图指令子系统。
4. 重写战斗命令、BP、破防、属性、伤害、恢复、状态和道具。
5. 在原作装备框架上重新接入六相材料、装备成长和炼药。
6. 重新设计四门与最终魔王的职业相性，允许各首领偏爱或克制部分职业，并公开相性依据。
7. 重做组合审计、逐回合模拟和经济模拟；记录组合强弱分布，不把“无弱组合”设为通过条件。
8. 全部通过后，才生成数据库与前端实现计划。

## 10. 验收标准

- 任意规则都能回答“原作行为是什么、为何保留或为何必须适配”。
- 不再出现一条未经原作依据或用户再次确认的旧硬限制压过原作机制。
- 八基础职业、八角色固有层、通用异常、装备、道具、EXP／JP／金币均有完整来源映射。
- 适配不会修改真实工作记录和已锁定结算。
- 强组合通过公开敌人机制、资源和阶段接受考验，而不是被系统暗中削弱。
- 弱组合可以保留并被如实标注；不得为了配平组合而改写职业核心技能。
- 首领职业偏向可以明显存在，但必须可从弱点、意图、阶段或图鉴中理解。
- 所有原作沿用项使用简体中文版官方名称，原创内容明确标识为原创。
- 新平衡报告明确区分规则复现验证、经济模拟与实际逐回合胜率。
